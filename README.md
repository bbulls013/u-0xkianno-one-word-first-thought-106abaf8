My first thought was **psithurism**: the sound of wind moving through trees, leaves whispering to each other. It names a feeling everyone has heard but almost no one has a word for, and saying it aloud almost performs the sound itself. Ten letters, one clear image, no filler.

## How to run

```bash
python3 main.py
```

This writes the single word to `/output/entry.txt` (UTF-8, no trailing newline). The output is deterministic — byte-identical on every run. Python standard library only; no dependencies.
